Text Processing Pipeline:
We implemented a sophisticated text processing pipeline that included:
```python
def clean_tweet(text):
    # Remove URLs, mentions, hashtags
    text = re.sub(r'http\S+|@\w+|#\w+', '', text)
    # Remove special characters
    text = re.sub(r'[^\w\s]', '', text)
    # Remove extra whitespace
    text = ' '.join(text.split())
    return text
```

Technical Challenges Encountered:

1. Data Quality Issues:
- Temporal misalignment:
  * Sales data reported monthly
  * Tweet data had irregular daily patterns
  * Example: January 2020 showed 3,500 tweets but only 1,200 were relevant
- Noise in social media data:
  * Many promotional tweets (approximately 25%)
  * Bot-generated content (identified ~15% automated posts)
  * Duplicate information across retweets

2. Model Performance Issues:
- High variance in predictions:
  * RMSE: 12,500 vehicles
  * Mean Absolute Percentage Error: 45%
- Poor generalization:
  * Training R² = 0.75
  * Test R² = 0.30
  * Clear indication of overfitting

3. Feature Engineering Challenges:
- Sentiment aggregation problems:
  * Daily sentiment scores showed high volatility
  * Monthly aggregation lost important temporal patterns
- Engagement metrics proved unreliable:
  * Retweet counts skewed by viral but irrelevant content
  * Like counts didn't correlate well with actual market impact

Key Lessons from Initial Approach:

1. Data Quality > Quantity:
- Having 100,000 tweets proved less valuable than having quality, relevant content
- Example: A single verified Tesla analyst's tweet often provided more predictive value than 1,000 general tweets

2. Temporal Alignment is Crucial:
- Monthly sales data required careful aggregation of daily social media signals
- Moving averages and weighted temporal features showed promise
- Example: 3-day moving averages of sentiment scores reduced noise while preserving trends

3. Feature Selection Insights:
- Most predictive features:
  * Previous month's sales (20.4%)
  * Seasonal patterns (20.5%)
  * Verified user sentiment (15.2%)
- Least useful features:
  * Raw retweet counts
  * General public sentiment
  * Daily tweet volumes

This initial setback led us to reassess our approach and search for more reliable data sources. We realized that while social media data could be valuable, we needed to be more selective about our data sources and combine them with more structured information. The experience taught us the importance of data quality over quantity and the need for domain-specific feature engineering.
